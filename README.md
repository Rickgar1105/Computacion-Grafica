# Práctica 6: Texturizado

- Practica6/: proyecto C++, CMake, texturas, modelos OBJ/MTL, editables Blender y evidencias de ejecución.
- Release/Practica6Texturizado.app: ejecutable para macOS ARM64, verificado en el Mac de trabajo. Depende de las bibliotecas Homebrew instaladas en ese equipo; puede requerir recompilar en otro Mac.
- Reporte_Practica6_Ricardo_Galicia.docx y .pdf: reporte con la plantilla institucional.
- LEEME.md: instrucciones, controles y compilación.

Los ejercicios incluyen un holocrón por código, un holocrón importado con las seis imágenes proporcionadas y un avión texturizado como recreación simplificada de la referencia. Los shaders de texturizado son los del curso. La geometría se modeló mediante la interfaz de Blender.
